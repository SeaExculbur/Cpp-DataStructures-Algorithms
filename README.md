# C/C++ 课程与数据结构算法学习记录

一个从 C 语言课程出发、逐步推进到数据结构和算法的学习仓库。所有练习同时提供 **C 与 C++ 双版本实现**，并配有带测试用例的题目说明，既是我个人的学习档案，也希望能给同样在学 C/C++ 的人一点参考。

## 仓库内容

| 目录 | 内容 |
|------|------|
| `Term1/` ~ `Term5/` | C 语言课程主线：基础语法 → 函数与数组 → 算法入门（冒泡、二分/插值查找）→ 指针/函数指针/字符串/结构体/文件 I/O → 日期时间 |
| `data_structrue/` | 数据结构专题：动态顺序表、单链表、顺序栈、循环队列、二叉树、图（邻接矩阵/邻接表、DFS/BFS），以及综合复习题 |
| `Algorithm/` | 算法专题：递归（10 题）、排序（插入/希尔/选择/快排/归并/堆/计数），学习路线见 [学习规划](Algorithm/学习规划.md) |
| `string/` | 字符串与指针专项训练（针对 xv6 lab 暴露的薄弱点设计） |
| `LeetCode/` | LeetCode 刷题记录 |
| `HomeWork/` | 课程作业 |

## 特色

- **C/C++ 双版本对照**：同一道题在 `C/` 和 `C++/` 下各写一遍。C++ 版本刻意保持和 C 相近的写法（用 `struct` 而非 `class`），降低对照学习的成本
- **题目说明独立成文**：每个专题的 `.md` 文件包含题目背景、结构体定义、测试用例和两套参考代码，实现文件里是实际提交的解答
- **重写式练习**：不少题目保留 `v1`/`v2` 多个版本——先写完初版，隔段时间删掉重写一遍，检验是否真正掌握

## 编译运行

本仓库无构建系统，每个文件独立编译，产物为同目录下的 `.exe`：

```bash
# C 版本
gcc -g 文件名.c -o 文件名.exe && ./文件名.exe

# C++ 版本
g++ -g 文件名.cpp -o 文件名.exe && ./文件名.exe
```

环境：MinGW-w64 GCC/G++（含 `<stdio.h>`/`<iostream>` 等标准库即可，无第三方依赖）。
