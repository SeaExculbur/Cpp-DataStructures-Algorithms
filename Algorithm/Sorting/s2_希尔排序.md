# Sorting 2: Shell Sort 希尔排序

> 面试出现频率较低，蓝桥杯偶见。重点在理解"分组 + 插入"的思想。

## 题目

实现 `void ShellSort(int arr[], int n)`，对数组原地排序（升序），增量序列从 n/2 开始，每次减半直到 1。

## 核心思想

插入排序只能相邻移动、一次一步——太慢。希尔排序**按增量分组**：先让元素"跳着走"快速接近正确位置，最后增量为 1 时退化成普通插入排序（此时数组已基本有序，插入排序很快）。

```
增量 d = n/2，每轮：把下标相差 d 的元素分成一组，组内做插入排序
增量减半，重复，直到 d = 1
```

例：`{49, 38, 65, 97, 76, 13, 27, 49}`（n=8，两个 49 测稳定性）

```
d=4: 分组 (49,76) (38,13) (65,27) (97,49) → 组内排序
d=2: 分组 (49,65,76,27)... → 组内排序
d=1: 全体插入排序 → 结束
```

## 画图指引

- **第三张图**：d=1 时，整个数组做插入排序——此时数组已经"基本有序"，画出每轮移动的距离

## 面试 / 竞赛考点

- **复杂度**：最坏 O(n²)，平均约 O(n^1.3)（面试只需答"优于直接插入、但最坏还是 O(n²)"）
- **稳定性**：**不稳定**（相同元素可能被分到不同组，跨组交换破坏相对顺序）
- **面试常问**：为什么希尔排序比插入排序快？——每次移动的距离大，能快速把元素"送到"接近正确的位置
- 蓝桥杯极少直接考希尔，但"分组处理"的思想在分块/分桶类题目里有延伸

## 测试用例（C）

```c
void ShellSort(int arr[], int n);   // 你要实现的函数

// PrintArr 自己写

int main() {
    int a[] = {49, 38, 65, 97, 76, 13, 27};
    int n = 7;
    printf("排序前: "); PrintArr(a, n);
    ShellSort(a, n);
    printf("排序后: "); PrintArr(a, n);
    printf("预期: 13 27 38 49 65 76 97\n");

    // 带重复元素（体验不稳定性）
    int b[] = {49, 38, 65, 97, 76, 13, 27, 49};
    ShellSort(b, 8);
    printf("重复元素: "); PrintArr(b, 8);
    printf("预期: 13 27 38 49 49 65 76 97\n");
    return 0;
}
```
