# Sorting 4: Quick Sort 快速排序（分治）

> LeetCode 对应：#912 排序数组
> 变种题：#215 数组中的第 K 个最大元素（见文末进阶）

## 题目

实现 `int Partition(int arr[], int low, int high)` 和 `void QuickSort(int arr[], int low, int high)`，对数组 `[low, high]` 区间原地排序（升序）。

## 核心思想

分治三步：

1. **划分**：选一个基准（一般取 `arr[low]`），把数组分成"左边都 ≤ 基准、右边都 ≥ 基准"两部分，返回基准最终的位置
2. **递归左半**：`QuickSort(arr, low, pivot-1)`
3. **递归右半**：`QuickSort(arr, pivot+1, high)`

终止条件：区间为空或只剩一个元素（`low >= high`）。

## Partition 的过程（经典写法）

用 `{49, 38, 65, 97, 76, 13, 27}` 模拟一次划分（基准 49）：

```
low→                      ←high
[49, 38, 65, 97, 76, 13, 27]
high 从右往左找 <49 的 → 找到 27
[27, 38, 65, 97, 76, 13, 27]    ← 27 覆盖 low 位置
low 从左往右找 >49 的 → 找到 65
[27, 38, 65, 97, 76, 13, 65]    ← 65 覆盖 high 位置
high 继续找 <49 的 → 找到 13
[27, 38, 13, 97, 76, 13, 65]
low 继续找 >49 的 → 找到 97
[27, 38, 13, 97, 76, 97, 65]
low == high → 基准 49 落位
[27, 38, 13, 49, 76, 97, 65]    ← 划分完成，返回位置 3
```

## 面试 / 竞赛考点

- **复杂度**：平均 O(n·log₂n)，**最坏 O(n²)（已有序/逆序数组）**，空间 O(log₂n)（递归栈）
- **稳定性**：**不稳定**
- **面试必问**："数组基本有序时，快排为什么反而最慢？"——每次划分只分出 1 个和 n-1 个，退化成 O(n²)。改进：随机选基准、三数取中
- **面试必问**："为什么工程上不用纯快排？"——递归栈可能爆 + 最坏情况，所以 std::sort 是"快排 + 插入排序 + 堆排序"混合
- **蓝桥杯**：快排手写是基础功，但竞赛一般用 sort()；快排的价值在**快速选择**（下面变种）

## 进阶变种：第 K 大（LeetCode #215）

快排的划分有个副产品：**每趟划分后，基准的位置就是它在有序数组中的最终位置**。所以找第 K 大不用排完——划完只递归基准所在的那一边：

```c
int FindKthLargest(int arr[], int n, int k);  // 找第 k 大（k 从 1 开始）
// 思路: 目标下标 target = n - k（0 基）
// 每次 Partition 后: pivot 下标 == target → 返回
//                    pivot 下标 > target  → 只递归左边
//                    pivot 下标 < target  → 只递归右边
// 平均 O(n)（等比数列求和），最坏 O(n²)
```

这道题蓝桥杯和面试都是高频，写完快排后把变种也做了。

```c
    printf("排序后: "); PrintArr(a, n);
    printf("预期: 13 27 38 49 65 76 97\n");

    // 最坏情况：已经有序的数组
    int b[] = {1, 2, 3, 4, 5};

    printf("有序数组: "); PrintArr(b, 5);
    printf("预期: 1 2 3 4 5\n");
    return 0;
}
```
