# Sorting 5: Merge Sort 归并排序（分治）

> LeetCode 对应：#912 排序数组
> 变种题：#148 排序链表、#493 翻转对 / 剑指 Offer 51 数组中的逆序对（见文末进阶）

## 题目

实现 `void Merge(int arr[], int low, int mid, int high)` 和 `void MergeSort(int arr[], int low, int high)`，对数组 `[low, high]` 区间原地排序（升序）。

## 核心思想

分治三步（和快排相反——快排"先分后治"，归并"先治后分"）：

1. **分解**：把区间从中间分成两半
2. **递归**：`MergeSort(arr, low, mid)` 和 `MergeSort(arr, mid+1, high)` 各自排好
3. **合并**：`Merge` 把两个**已经各自有序**的半边合并成一个整体有序的区间

终止条件：区间为空或只剩一个元素（`low >= high`）——一个元素天然有序。

## Merge 的过程（需要辅助数组）

```
待合并: 左半边 [27, 38, 49]   右半边 [13, 65, 76]

复制到辅助数组 B 后，三个指针 i(左半起点) j(右半起点) k(写回位置)：

比较 B[i]=27 和 B[j]=13 → 13 小，写回，j++
比较 27 和 65 → 27 写回，i++
比较 38 和 65 → 38 写回，i++
比较 49 和 65 → 49 写回，i++
左半边用完 → 右半边剩余 65 76 依次写回

结果: [13, 27, 38, 49, 65, 76]
```

**关键**：合并前先把 `arr[low..high]` 复制到辅助数组（用局部数组/静态数组/全局数组自己决定），合并时从辅助数组里取、往 arr 里写。

## 面试 / 竞赛考点

- **复杂度**：O(n·log₂n)（**所有情况都是**，没有最坏），空间 **O(n)**（辅助数组）
- **稳定性**：**稳定**
- **面试必问**：归并和快排的区别？——归并"先递归后合并"（排序发生在归的路上）、快排"先划分后递归"（排序发生在分的路上）。归并稳定但空间 O(n)；快排不稳定但空间 O(log₂n)
- **蓝桥杯/面试高频变种**：数组中的逆序对（见下）

## 进阶变种：逆序对计数（剑指 Offer 51）

归并排序的"合并"过程能顺便统计逆序对：

```
合并时，如果右半边元素 B[j] < 左半边元素 B[i]，
那么 B[i] 及左半边剩余的所有元素 都比 B[j] 大——一次就统计出一批逆序对
```

```c
int MergeCount(int arr[], int low, int mid, int high);  // 合并 + 返回本层逆序对数
long long ReversePairs(int arr[], int low, int high);   // 递归 + 累加
// 例: [7, 5, 6, 4] 的逆序对 = (7,5)(7,6)(7,4)(5,4)(6,4) = 5
```

这题的考点就是"归并过程数数"，写完归并排序后做。
