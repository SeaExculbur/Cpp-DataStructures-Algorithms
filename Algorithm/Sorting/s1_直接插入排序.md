# Sorting 1: Insertion Sort 直接插入排序

> LeetCode 对应：#912 排序数组（本题可作其解法之一）

## 题目

实现 `void InsertSort(int arr[], int n)`，对数组原地排序（升序）。

## 核心思想

把数组分成"已排序区"和"未排序区"。每轮取未排序区的第一个元素，**从后往前**在已排序区中找到它该插入的位置，把后面的元素依次后移，然后插入。

```
初始: [49, 38, 65, 97, 76]   已排序区=前1个 [49]，未排序区=[38,65,97,76]

第1轮: 取 38，在 [49] 中找位置 → 49 后移 → [38, 49, 65, 97, 76]
第2轮: 取 65，65 > 49 不动   → [38, 49, 65, 97, 76]
第3轮: 取 97，不动           → [38, 49, 65, 97, 76]
第4轮: 取 76，97 后移，76 插到 65 后面 → [38, 49, 65, 76, 97]
```

## 面试 / 竞赛考点

- **复杂度**：最好 O(n)（已有序）、最坏/平均 O(n²)、空间 O(1)
- **稳定性**：稳定
- **面试加分点**：插入排序在**近似有序**或**规模小**时，比快排/归并还快——所以工程上（Python 的 TimSort、C++ std::sort）会在递归到底层时改用插入排序。面试官问"为什么排序库不全程用快排"时，这是核心答案
- **蓝桥杯**：适合小规模排序，实现最简单、不容易写错

## 测试用例（C）

```c
void InsertSort(int arr[], int n);   // 你要实现的函数

// PrintArr 自己写

int main() {
    int a[] = {49, 38, 65, 97, 76, 13, 27};
    int n = 7;
    printf("排序前: "); PrintArr(a, n);
    InsertSort(a, n);
    printf("排序后: "); PrintArr(a, n);
    printf("预期: 13 27 38 49 65 76 97\n");

    // 边界：单元素、空数组
    int b[] = {5};
    InsertSort(b, 1);
    printf("单元素: %d（预期 5）\n", b[0]);
    return 0;
}
```
