# Sorting 3: Selection Sort 简单选择排序

> 面试低频，但它是"每趟选最值"思想的代表，是堆排序的铺垫。

## 题目

实现 `void SelectSort(int arr[], int n)`，对数组原地排序（升序）。

## 核心思想

每趟从**未排序区**中选出最小元素，和第 i 个位置交换。

```
初始: [49, 38, 65, 97, 76, 13, 27]
第1趟: 全数组最小是 13 → 和 49 交换 → [13, 38, 65, 97, 76, 49, 27]
第2趟: 未排序区 [38,65,97,76,49,27] 最小 27 → 和 38 交换 → [13, 27, 65, 97, 76, 49, 38]
第3趟: 未排序区最小 38 → 和 65 交换 → [13, 27, 38, 97, 76, 49, 65]
...
```

## 画图指引

用 `{49, 38, 65, 97, 76, 13, 27}`：

- **第一张图**：画出初始数组，竖线分隔"已排序区 | 未排序区"
- **第二张图**：每一趟，圈出未排序区的最小元素，用箭头标出它和当前交换位置元素**交换**的过程
- **第三张图**：画完 4 趟后，标出已排序区和未排序区的边界移动

## 和插入排序的区别

| | 直接插入 | 简单选择 |
|---|---|---|
| 每趟做的事 | 取未排序区**第一个**，插入已排序区 | 在未排序区**找出最小**，放已排序区末尾 |
| 比较次数 | 与有序程度有关 | **固定** n(n-1)/2（永远这么多） |
| 移动次数 | 与有序程度有关 | 最多 3(n-1) 次 |
| 稳定性 | 稳定 | **不稳定**（隔很远交换，破坏相对顺序） |

## 面试 / 竞赛考点

- **复杂度**：比较次数恒定 O(n²)、移动 O(n)、空间 O(1)
- **稳定性**：**不稳定**（例：`{2, 2, 1}`——第一个 2 和 1 交换，两个 2 相对顺序翻转）
- **面试常问**：和插入排序对比——"什么时候选择排序比插入排序好？"答：移动代价高（写操作贵）的场景，选择排序移动次数固定且少
- **思想延伸**：每趟选最值 = 堆排序的原型（堆把"找最值"从 O(n) 加速到 O(log n)）

## 测试用例（C）

```c
void SelectSort(int arr[], int n);   // 你要实现的函数

// PrintArr 自己写

int main() {
    int a[] = {49, 38, 65, 97, 76, 13, 27};
    int n = 7;
    printf("排序前: "); PrintArr(a, n);
    SelectSort(a, n);
    printf("排序后: "); PrintArr(a, n);
    printf("预期: 13 27 38 49 65 76 97\n");

    // 不稳定性体验：{2, 2, 1} 排序后是 {1, 2, 2}，但两个 2 的相对位置可能翻转
    int b[] = {2, 2, 1};
    SelectSort(b, 3);
    printf("重复元素: "); PrintArr(b, 3);
    printf("预期: 1 2 2\n");
    return 0;
}
```

**vector 版和裸数组版的差异**：

| | 裸数组版 | vector 版 |
|---|---|---|
| 签名 | `void SelectSort(int arr[], int n)` | `void SelectSort(vector<int>& v)` |
| 长度 | 额外传 `n` | `v.size()` 自带 |
| 传参 | `SelectSort(a, n)` | `SelectSort(a)`（必须传引用，否则拷贝） |
| 交换 | 自己写 swap 函数 | 直接用 `std::swap`（bits 头已包含） |
