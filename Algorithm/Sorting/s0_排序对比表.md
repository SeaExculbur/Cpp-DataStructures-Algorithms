# Sorting 总表：复杂度 / 稳定性 / 高频问题

> 做题前先看这张表。面试的排序问题 80% 从这里出。

## 一、总表

| 排序 | 最好 | 平均 | 最坏 | 空间 | 稳定性 | 方法 |
|------|------|------|------|------|:---:|------|
| 直接插入 | O(n) | O(n²) | O(n²) | O(1) | **稳定** | 插入 |
| 希尔 | O(n^1.3) | — | O(n²) | O(1) | **不稳定** | 插入(分组) |
| 冒泡 | O(n) | O(n²) | O(n²) | O(1) | **稳定** | 交换 |
| 快速 | O(n·log₂n) | O(n·log₂n) | **O(n²)** | O(log₂n) | **不稳定** | 交换(分治) |
| 简单选择 | O(n²) | O(n²) | O(n²) | O(1) | **不稳定** | 选择 |
| 堆排序 | O(n·log₂n) | O(n·log₂n) | O(n·log₂n) | O(1) | **不稳定** | 选择(堆) |
| 归并 | O(n·log₂n) | O(n·log₂n) | O(n·log₂n) | **O(n)** | **稳定** | 归并 |
| 计数 | O(n+k) | O(n+k) | O(n+k) | O(k) | **稳定** | 非比较 |

（n=元素个数，k=值域大小）

## 二、背诵口诀

- **稳定的排序**：插入、冒泡、归并、计数（"插冒归计"四个稳定）
- **不稳定**：希尔、快排、简单选择、堆（"快选堆希"四个不稳定）
- **每趟确定一个元素最终位置**：选择、堆排序（每趟堆顶落位）、快排（每趟枢轴落位）
- **和初始有序程度相关的**：插入（有序时快）、快排（**有序时最慢**——最坏 O(n²)）
- **任何情况都是 O(n·log₂n)**：归并、堆排序
- **空间 O(1)**：插入、希尔、冒泡、选择、堆
- **空间 O(n)**：归并（辅助数组）、计数（count 数组）

## 三、面试高频问题（背诵答案）

### 1. 为什么数组基本有序时快排反而最慢？

每次划分只分出 1 个元素和 n-1 个元素，递归深度 O(n)，总比较 O(n²)。改进：随机选基准、三数取中。**这是排序里最常考的一问。**

### 2. 归并和快排有什么区别？

- 归并"先递归后合并"（排序发生在归的路上），快排"先划分后递归"（排序发生在分的路上）
- 归并稳定但空间 O(n)；快排不稳定但空间 O(log₂n)
- 两者最好情况都是 O(n·log₂n)，但快排最坏 O(n²)、归并没有最坏

### 3. 为什么工程上不用纯快排？

递归可能爆栈 + 最坏 O(n²)。`std::sort` 的做法：快排为主，递归深了切堆排序兜底（保证 O(n·log₂n)），区间小于 16 时切插入排序（小规模插入最快）。

### 4. 为什么堆排序实际比快排慢？

常数大（HeapAdjust 每层比较多次）+ 缓存不友好（跳跃访问）。但它的价值是**最坏也 O(n·log₂n)** + 空间 O(1)。

### 5. 什么时候用什么排序？

| 场景 | 选择 | 原因 |
|------|------|------|
| 数据量大、通用 | 快排（std::sort） | 平均最快 |
| 数据基本有序 / 规模小 | 插入排序 | O(n) |
| 要求稳定 | 归并 | 稳定 + O(n·log₂n) |
| 数据值域小（成绩等） | 计数排序 | O(n+k) 碾压比较排序 |
| 只求第 K 大 / TopK | 堆排序（小根堆） | O(n·log K) |

### 6. 为什么求第 K 大用"大小为 K 的小根堆"？

小根堆堆顶是堆里最小的。新元素 > 堆顶 → 弹出堆顶、放入新元素。遍历完，堆里就是最大的 K 个，堆顶是第 K 大。大根堆反而做不到——它的堆顶是最大的，你无法知道"第 K 大"在哪。

## 四、容易混淆的点

1. **选择排序的比较次数恒定**是 O(n²)——不管数组什么样，永远比较这么多；插入排序则和有序程度有关
2. **归并的 O(n·log₂n) 稳定是指复杂度稳定**（无最坏），**稳定性是指相等元素不交换**——两个"稳定"是不同概念
3. **堆排序是选择排序的加速版**——每趟都是"选最大"，只是用堆把"找最大"从 O(n) 降到 O(log n)

## 六、竞赛 C++ 模板速查（蓝桥杯 / ACM 常用）

### 6.1 万能头文件

```cpp
#include <bits/stdc++.h>   // 一次包含所有标准库
using namespace std;
```

蓝桥杯考场是 GCC 环境，这一行代替 iostream / vector / algorithm 等全部 include。（注意：MSVC 不支持这个头文件，本地用 MinGW 没问题）

### 6.2 快速 IO（数据量大时必加）

```cpp
int main() {
    ios::sync_with_stdio(false);   // 关闭 cin/cout 与 C 标准 IO 的同步
    cin.tie(0);                     // 解除 cin 和 cout 的绑定
    // ...
}
```

加了之后 cin/cout 的速度接近 scanf/printf。注意：加了之后**不要混用** scanf/printf 和 cin/cout。

### 6.3 竞赛模板骨架

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1e5 + 10;   // 数组最大规模（比题目上限多留几位防越界）
int a[N];                  // 全局数组：自动清零、不会爆栈
int n;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];

    // 处理逻辑……

    return 0;
}
```

与本题库的写法差异：练习用**硬编码测试数组**（写完直接跑、自动比对），比赛用**键盘读入**（stdin 数据）。练熟后切换成读入版即可。

### 6.4 常用 STL 速查

| 需求 | 写法 |
|------|------|
| 排序（升序） | `sort(a, a + n);` 或 `sort(v.begin(), v.end());` |
| 排序（降序） | `sort(a, a + n, greater<int>());` |
| 交换 | `swap(x, y);` |
| 最值 | `max(x, y);` `min(x, y);` |
| 绝对值 | `abs(x);` |
| 数组清零 | `memset(a, 0, sizeof(a));` |
| 第 K 大 | `nth_element(a, a + k, a + n);`（O(n)，快选的标准库版） |
| 去重（需先排序） | `unique(a, a + n) - a;` 得到新长度 |

### 6.5 一个提醒

比赛里排序题**直接 `sort()` 就能过**（O(n·log₂n)，常数还小），手写排序的价值在于：

- 面试白板、考研手写题会考
- 分治（归并/快排）、堆的思想是 DP、贪心的基础
- 变种题（第 K 大、逆序对计数）需要手写改造

所以：**练习时手写掌握原理 → 比赛时用 sort() 省时间**。
