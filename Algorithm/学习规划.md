## 三、阶段详解

### 阶段 1：排序全家桶

**内容**：插入排序、希尔排序、快排（递归）、归并（递归）、堆排序、稳定性与复杂度对比表

- 快排、归并是递归的直接应用——递归刚学完，写起来最顺
- **408 必背**：所有排序的时间/空间/稳定性对比表（每年都考）

**验收**：C/C++ 双版本各写一遍，能默写快排和归并

### 阶段 2：堆

**内容**：堆的存储（数组）、建堆、堆排序、TopK / 第 K 大

- 堆排序依赖堆，所以插在排序阶段学
- TopK 是面试高频（大文件 TopK、海量数据）

### 阶段 3：图论（数据结构最大缺口）

**内容**：邻接矩阵 / 邻接表存储、DFS / BFS（注意 visited 标记，和树不同）、最小生成树（Prim/Kruskal）、最短路（Dijkstra/Floyd）、拓扑排序

- **考研重点**：MST、Dijkstra、Floyd、拓扑排序（手写 + 手动模拟）
- **蓝桥杯重点**：BFS 求迷宫最短路——蓝桥必考题型

### 阶段 4：查找 + 树进阶 + KMP

**内容**：BST 复习、AVL、B树/B+树、哈希表、KMP

- AVL、B树：考研硬考点（概念 + 构造过程），面试基本不考
- 哈希表：**面试第一高频**（两数之和全家桶），练到条件反射
- KMP：考研必考（next 数组），蓝桥偶尔出现

### 阶段 5：算法范式（蓝桥杯 + 面试笔试核心）

学习顺序（依赖递进）：**分治 → 回溯 → 贪心 → 动态规划**

| 范式 | 代表题 | 说明 |
|------|-------|------|
| 分治 | 快排、归并深挖、第 K 大 | 递归的直接延伸 |
| 回溯 | 全排列、子集、N 皇后 | 蓝桥暴力搜索的根基 |
| 贪心 | 区间调度、哈夫曼、部分背包 | 和回溯形成对比 |
| 动态规划 | 背包、LIS、LCS、区间 DP | **重头戏**；爬楼梯已埋伏笔：递推 → 记忆化 → DP |

### 阶段 6：技巧 + 冲刺

**内容**：双指针、滑动窗口、前缀和、单调栈/队列、位运算、数论基础（gcd、素数、快速幂）、字符串

**冲刺模式**：
- 蓝桥杯：刷历年省赛真题
- 面试：LeetCode 按专题刷 + 剑指 Offer
- 笔试：牛客高频题 + 手写速度训练（边界、复杂度分析）

- 面试特有：哈希、TopK、链表经典题、手写速度
