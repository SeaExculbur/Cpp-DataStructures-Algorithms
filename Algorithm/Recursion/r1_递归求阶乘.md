# 递归练习1：阶乘

## 题目

用递归实现 `int Factorial(int n)`，返回 `n!`。

## 最小子结构

```
n=0: 0! = 1                   ← 最小的：直接返回固定值
n>0: n! = n × (n-1)!          ← 拆成一个乘法 + 更小的阶乘
```

## 思路

事实：`Factorial(4)` 不应该去脑补 `Factorial(3)` 内部怎么算。你只管两件事：

1. `n==0` 时返回 `1`（终止条件）
2. `n>0` 时返回 `n × Factorial(n-1)`（`n-1` 比 `n` 小，在缩小）

## 测试用例（C）

```c
int main() {
    printf("0! = %d（预期 1）\n", Factorial(0));
    printf("1! = %d（预期 1）\n", Factorial(1));
    printf("5! = %d（预期 120）\n", Factorial(5));
    printf("10! = %d（预期 3628800）\n", Factorial(10));
    return 0;
}
```
