# 递归练习2：斐波那契数列

## 题目

用递归实现 `int Fib(int n)`，返回第 n 项斐波那契数。

```
Fib(0) = 0, Fib(1) = 1
Fib(n) = Fib(n-1) + Fib(n-2)   (n >= 2)
```

## 最小子结构

```
n=0: 返回 0
n=1: 返回 1                  ← 两个最小结构
n>1: Fib(n-1) + Fib(n-2)     ← 拆成两个更小的问题，每个都在缩小
```

## 思路

和树的深度公式几乎一样——树是 `1 + max(左, 右)`，这个是 `Fib(n-1) + Fib(n-2)`。两个都是"当前 = 左结果 + 右结果"，只是具体公式不同。

## 测试用例（C）

```c
int main() {
    printf("Fib(0) = %d（预期 0）\n", Fib(0));
    printf("Fib(1) = %d（预期 1）\n", Fib(1));
    printf("Fib(2) = %d（预期 1）\n", Fib(2));
    printf("Fib(5) = %d（预期 5）\n", Fib(5));
    printf("Fib(10) = %d（预期 55）\n", Fib(10));
    // 别测 n=50——纯递归会超时（原因后面再讲）
    return 0;
}
```
