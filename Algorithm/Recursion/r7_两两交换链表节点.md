# 递归变种练习7：两两交换链表节点（≈ LeetCode #24）

## 题目

给定一个单链表，将每两个相邻节点交换位置。

```
输入: 1 → 2 → 3 → 4 → NULL
输出: 2 → 1 → 4 → 3 → NULL

输入: 1 → 2 → 3 → NULL
输出: 2 → 1 → 3 → NULL  （奇数个节点时最后一个不换）
```

- **第三张图**：如果你已经递归解决了 `3 → NULL` 的子问题，现在要处理 1 和 2 这一对——画出"交换前"和"交换后"，标记递归调用返回后你需要改哪些指针

## 和 Q3 的关系

Q3 的反转链表是"所有节点全部反转"，这题是"两个一组反转"。
Q3 的递推模式：反转"后面"→把当前节点挂到后面节点的后面
这题呢？交换当前两个→把剩下的递归处理→把当前两个连到处理好的结果上
