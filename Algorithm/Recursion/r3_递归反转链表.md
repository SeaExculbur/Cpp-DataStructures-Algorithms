# 递归练习3：递归反转链表

## 题目

用递归实现 `ListNode* ReverseList(ListNode *head)`，反转单链表（带头结点或无头结点均可，自己约定）。

你之前已用三指针迭代法写过反转，这次换成递归。

## 结构体

```c
typedef struct ListNode {
    int data;
    struct ListNode *next;
} ListNode;
```

## 最小子结构

```
空链表 / 单节点链表        → 直接返回 head（不需要反转）
多节点链表: head → [其余节点]
  反转"其余节点" → 把 head 挂到原后继的后面 → 返回新头
```

```
反转前:  1 → 2 → 3 → NULL

ReverseList(1):
  newHead = ReverseList(2)      // 拆：剩下 2→3
    = ReverseList(3)
      = 3（单节点，返回自己）
  2->next->next = 2  // 把 2 挂到 3 后面 → 3→2
  2->next = NULL      // 2 变成尾
  返回 3

结果: 3 → 2 → 1 → NULL
```

## 测试用例（C）

```c
// 建表函数: ListNode* BuildList(int arr[], int n) { ... }

int main() {
    int arr1[] = {1, 2, 3, 4, 5};
    ListNode *head = BuildList(arr1, 5);
    head = ReverseList(head);
    printf("反转后: ");
    for (ListNode *p = head; p; p = p->next) printf("%d ", p->data);
    printf("\n预期: 5 4 3 2 1\n");

    // 单节点
    ListNode *single = BuildList((int[]){7}, 1);
    single = ReverseList(single);
    printf("单节点: %d（预期 7）\n", single->data);

    // 空链表
    printf("空链表: %s\n", ReverseList(NULL) == NULL ? "NULL ✅" : "❌");

    return 0;
}
```
