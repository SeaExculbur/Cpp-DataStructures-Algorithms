# 递归变种练习8：翻转二叉树（≈ LeetCode #226）

## 题目

翻转一棵二叉树——将每个节点的左右孩子交换。

```
翻转前:         翻转后:
      4              4
    /   \          /   \
   2     7        7     2
  / \   / \      / \   / \
 1   3 6   9    9   6 3   1
```

## 画图指引

- **第一张图**：画一棵简单的三层树（就用上面的 4 2 7 1 3 6 9）
- **第二张图**：只翻转根节点的两个孩子——4 的左变成 7、右变成 2，画出来。此时子树内部还没翻
- **第三张图**：递归到底发生了什么？在最底层的 `1` 和 `3` 叶子节点——空节点翻转后还是空，`1` 的左右都是空，交换后不变。那回到 `2` 这层——左子树 `1` 已翻转完、右子树 `3` 已翻转完，现在交换左右——画出交换前和交换后

## 和 Q4、Q5 的关系

Q4 是后序遍历取 max——左边算好、右边算好、根再合并
Q5 是对称比较——左左对右右、左右对右左

翻转二叉树是**后序遍历 + 交换**：左边翻好了、右边翻好了、根交换左右孩子。

**注意**：翻转后，原本的左子树变成了右子树。这意味着你在递归返回路上做的操作和"先递归、再处理当前"有何关系？

```c
    // 空树
    printf("空树: %s\n", InvertTree(NULL) == NULL ? "NULL ✅" : "❌");

    // 单节点
    TreeNode *s = CreateNode(42);
    s = InvertTree(s);
    printf("单节点值=%d（预期 42）\n", s->data);
    return 0;
}
```
