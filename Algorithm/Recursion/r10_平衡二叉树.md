# 递归变种练习10：平衡二叉树（≈ LeetCode #110）

## 题目

判断一棵二叉树是否是**高度平衡**的——每个节点的左右子树高度差不超过 1。

```
平衡✅:      3           不平衡❌:     1
           /   \                    /   \
          9    20                 2     3
              /  \               / \
             15   7             4   5
                                    / \
                                   6   7
```

## 画图指引

用上面不平衡的例子：
- **第一张图**：画出整棵树的结构
- **第二张图**：在每个节点旁边标注它的"左子树高度"和"右子树高度"，比如根节点 1：左高=3，右高=1，差=2 > 1 → 不平衡
- **第三张图**：递归是后序——先算出所有子节点的高度，再往上算。画出"计算高度"的递推方向

## 和 Q4 的关系

Q4 是后序遍历**算最大值**——收集子问题的答案，合并
这题是后序遍历**算高度 + 顺便判断平衡**——需要同时传回**两个信息**（高度是多少？是否平衡？）

这就是递归的另一个常见模式：**返回值不够用时，要么用辅助函数多传参数，要么用指针/引用带出额外信息**。

思考一个问题：Q4 的返回值就是一个 int（最大值），这道题需要"高度"和"是否平衡"两个信息，你打算怎么传？在纸上列出至少两种方案再动手。
