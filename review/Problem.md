### 题目1：指针操作数组（难度：★☆☆）

编写函数 `void reverse(int *arr, int size)`，**只允许使用指针运算**（不允许出现 `[ ]`），将数组元素就地逆序。
在 `main` 中定义数组 `int a[] = {1,2,3,4,5,6};`，调用 `reverse` 后，再用指针遍历输出逆序后的数组。
**要求**：所有数组访问均通过指针完成。

### 题目2：指针函数 —— 返回最大值的地址（难度：★★☆）

编写函数 `int *max_element(int *arr, int n)`，返回指向数组中最大值的指针（若有多个最大值，返回第一个）。
在 `main` 中调用该函数，得到最大值地址后，**通过该指针将原数组中的最大值改为 0**，然后输出修改后的数组。假设数组长度至少为1。
**要点**：理解返回值为指针的函数如何定义和使用。

### 题目3：函数指针 —— 排序方式由回调决定（难度：★★★）

编写函数 `void sort(int *arr, int n, int (*cmp)(int, int))` 使用冒泡排序对数组排序。
再编写两个比较函数：

c

```
int ascending(int a, int b);   // 如果 a > b 返回真（用于升序）
int descending(int a, int b);  // 如果 a < b 返回真（用于降序）
```



在 `main` 中定义数组，由用户选择升序或降序，然后调用 `sort` 并输出排序结果。
**要求**：必须通过函数指针传递比较逻辑，不得在 `sort` 内直接判断升/降序。

### 题目4：函数指针数组 —— 菜单计算器（难度：★★★）

实现四个函数：`int add(int, int)`、`int sub(int, int)`、`int mul(int, int)`、`int div(int, int)`。
除法函数若除数为 0，输出错误信息并返回 0。
创建一个函数指针数组：`int (*ops[4])(int, int) = {add, sub, mul, div};`
编写循环菜单程序：提示用户输入两个整数和操作编号（0:+, 1:-, 2:*, 3:/），通过 `ops` 数组调用对应函数并输出结果。输入 -1 退出。
**提示**：练习函数指针数组的定义、初始化和调用。

### 题目5：指针函数数组（返回指针的函数数组）（难度：★★★★）

a) 编写三个函数：

c

```
char* get_hello();
char* get_world();
char* get_c();
```



分别返回字符串常量 `"Hello"`、`"World"`、`"C Language"` 的指针。
b) 声明并初始化一个**指针函数数组**（即数组中每个元素是一个返回 `char*` 的函数指针）：

c

```
char* (*func_table[3])();
```



将上述三个函数地址存入该数组，使用循环调用每个函数并打印其返回的字符串。
c) 再编写一个函数 `char* generate_msg(const char* name)`，内部用 `malloc` 创建字符串 `"Hello, 名字"`（名字由参数传入），并返回该动态内存的指针。
将 `generate_msg` 也加入一个可容纳4个函数的同类型数组中（可新定义一个 `char* (*func_table2[4])()`），调用该函数获得字符串，打印后**负责释放内存**。
**关键**：理解“指针函数数组”的声明语法，以及动态内存的管理。

### 题目6：复杂指针声明解读（难度：★★★）

请解释以下声明的含义，并尝试编写简单代码验证（能赋值、能通过指针调用/访问）：
a) `int *p[5];`
b) `int (*p)[5];`
c) `int *(*func)(int, double);`
d) `int (*func_arr[4])(char);`
e) `int *(*(*p)[3])(void);`

**要求**：对每个声明，用文字说明它是什么类型（如“p是……的指针”），并给出一个使用示例片段（如如何赋值、如何调用）。

------

**练习要求**：

- 不要使用任何宏定义；
- 不要使用链表、树等复杂数据结构（数组和字符串即可）；
- 尽量手动管理内存，注意 `malloc` 和 `free` 的配对；
- 在理解的基础上动手写代码，不要直接搜索完整答案。
