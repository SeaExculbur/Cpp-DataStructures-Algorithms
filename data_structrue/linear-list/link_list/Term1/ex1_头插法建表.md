# 练习1：头插法建立单链表

## 题目

使用**头插法**从键盘读取若干整数，建立一个**带头结点**的单链表。

- 输入 `9999` 时停止读取（`9999` 不存入链表）
- 打印链表所有数据节点的值

## 背景知识

| 建表方法 | 插入位置 | 结果 |
|----------|----------|------|
| 尾插法 | 新节点加在链表**尾部** | 链表顺序 = 输入顺序 |
| 头插法 | 新节点插在**头结点之后** | 链表顺序 = 输入顺序的**逆序** |

## 结构体定义（参考）

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```

## 输入输出示例

**输入：**
```
10
20
30
9999
```

**输出：**
```
30  20  10
```

## 提示

头插法的核心两步（设新节点为 `p`）：

```
p->next = L->next;   // 新节点接管原来的第一个数据节点
L->next = p;         // 头结点指向新节点
```

## 需要实现的函数

1. `void InitList(LinkList *L)` — 建立头结点，`(*L)->next = NULL`
2. `void List_HeadInsert(LinkList L)` — 头插法建表，`scanf` 循环读取
3. `void PrintList(LinkList L)` — 打印数据节点（跳过表头）
4. `void DestroyList(LinkList *L)` — 销毁链表，释放所有节点

## 测试用例

| 用例 | 输入 | 预期输出 |
|------|------|----------|
| 普通多节点 | 10, 20, 30, 9999 | 30 20 10 |
| 单节点 | 5, 9999 | 5 |
| 空表 | 9999 | （空表） |
