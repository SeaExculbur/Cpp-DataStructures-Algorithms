# 复习1：按位删除 `ListDelete`

## 结构体（与之前一致）

```c
#define Max_length 10
typedef struct {
    int *data;      // 堆上动态数组
    int MaxSize;    // 当前最大容量
    int length;     // 当前实际元素个数
} Sqlist;
```

位序从 1 开始计数。

## 函数签名

```c
int ListDelete(Sqlist *L, int position, int *deletedValue);
```

## 功能

删除顺序表 `L` 的第 `position` 个元素，被删元素的值通过 `deletedValue` 带出。
删除后，原位置之后的所有元素依次**前移一位**，`length` 减 1。

## 返回值

成功返回 1，失败返回 0。

## 失败情况

| 情况 | 返回值 |
|------|--------|
| 空表（`L->length == 0`） | 0 |
| `position < 1` | 0 |
| `position > L->length` | 0 |

## 元素前移示意

```
删除位置 3（值为 30）：
  前: [10, 20, 30, 40, 50]
              ↑ 删这个
  后: [10, 20, 40, 50]
          ↑40前移  ↑50前移
```

## 测试用例

| 操作 | 预期 |
|------|------|
| L = [10,20,30,40,50]，删除位序3 | 被删值=30，表变为 [10,20,40,50] |
| 再删除位序1（头删） | 被删值=10，表变为 [20,40,50] |
| 再删除位序3（尾删） | 被删值=50，表变为 [20,40] |
| 空表删除任意位序 | 返回 0 |
| 删除位序 0 | 返回 0 |
| 删除位序 99（超表长） | 返回 0 |

## 需要实现的辅助函数

- `void initlist(Sqlist *p)` — 初始容量 `Max_length`，`length = 0`
- `void printlist(Sqlist *L)` — 格式 `[10, 20, 30] (length=3)`
- `void buildList(Sqlist *L, int arr[], int n)` — 用数组快速构造顺序表
- `void destroyList(Sqlist *L)` — 释放 `data`
- `int ListDelete(Sqlist *L, int position, int *deletedValue)` — **实现这个**

## main 测试代码

```c
int main() {
    Sqlist L;
    int deletedValue;
    int ret;

    /* ---- 测试1：删除中间位置 ---- */
    int arr[] = {10, 20, 30, 40, 50};
    initlist(&L);
    buildList(&L, arr, 5);
    printf("初始："); printlist(&L);
    ret = ListDelete(&L, 3, &deletedValue);
    printf("删除位序3：ret=%d, 被删值=%d, 表：", ret, deletedValue);
    printlist(&L);
    printf("预期：ret=1, 被删值=30, 表：[10, 20, 40, 50]\n\n");

    /* ---- 测试2：头删 ---- */
    ret = ListDelete(&L, 1, &deletedValue);
    printf("删除位序1：ret=%d, 被删值=%d, 表：", ret, deletedValue);
    printlist(&L);
    printf("预期：ret=1, 被删值=10, 表：[20, 40, 50]\n\n");

    /* ---- 测试3：尾删 ---- */
    ret = ListDelete(&L, 3, &deletedValue);
    printf("删除位序3：ret=%d, 被删值=%d, 表：", ret, deletedValue);
    printlist(&L);
    printf("预期：ret=1, 被删值=50, 表：[20, 40]\n\n");

    /* ---- 测试4：空表删除 ---- */
    destroyList(&L);
    initlist(&L);                     // 重置为空表
    ret = ListDelete(&L, 1, &deletedValue);
    printf("空表删除位序1：ret=%d\n", ret);
    printf("预期：ret=0\n\n");

    /* ---- 测试5：删除位序0（非法） ---- */
    int arr2[] = {10, 20, 30};
    buildList(&L, arr2, 3);
    ret = ListDelete(&L, 0, &deletedValue);
    printf("删除位序0：ret=%d\n", ret);
    printf("预期：ret=0\n\n");

    /* ---- 测试6：删除位序99（超表长） ---- */
    ret = ListDelete(&L, 99, &deletedValue);
    printf("删除位序99：ret=%d\n", ret);
    printf("预期：ret=0\n");

    destroyList(&L);
    return 0;
}
```
