# 复习3：二分查找 `BinarySearch`

## 前提

顺序表必须是**升序**排列。

## 结构体（与之前一致）

```c
#define Max_length 10
typedef struct {
    int *data;
    int MaxSize;
    int length;
} Sqlist;
```

位序从 1 开始计数。

## 函数签名

```c
int BinarySearch(Sqlist *L, int value);
```

## 功能

在升序顺序表中用二分查找定位 `value`，返回其**位序**（从 1 开始）。
找不到返回 0。

## 算法思路

```
三个变量：left = 0, right = length - 1

while (left <= right) {
    mid = left + (right - left) / 2;   // 防溢出写法，等价于 (left+right)/2

    if (data[mid] == value) → 找到，return mid + 1（下标 → 位序）
    if (data[mid] < value)  → 目标在右半区，left = mid + 1
    if (data[mid] > value)  → 目标在左半区，right = mid - 1
}
return 0;
```

## 两个易错点

1. **循环条件**是 `left <= right`，不是 `left < right`。`<=` 保证单元素表也能正确判断。
2. **mid 计算**用 `left + (right - left) / 2` 而不是 `(left + right) / 2`，避免 `left + right` 在极端情况下溢出（虽然 int 顺序表一般不会，但养成习惯）。

## 测试用例

| 表 | 查找 | 预期 |
|----|------|------|
| [1, 3, 5, 7, 9, 11, 13] | 7 | 位序 4 |
| [1, 3, 5, 7, 9, 11, 13] | 1 | 位序 1（表头） |
| [1, 3, 5, 7, 9, 11, 13] | 13 | 位序 7（表尾） |
| [1, 3, 5, 7, 9, 11, 13] | 6 | 0（不存在，夹在中间） |
| [1, 3, 5, 7, 9, 11, 13] | -1 | 0（比最小值小） |
| [1, 3, 5, 7, 9, 11, 13] | 99 | 0（比最大值大） |
| [5]（单元素） | 5 | 位序 1 |
| [5]（单元素） | 3 | 0 |
| []（空表） | 任意 | 0 |

## 需要实现的辅助函数

- `void initlist(Sqlist *p)`
- `void buildList(Sqlist *L, int arr[], int n)`
- `void printlist(Sqlist *L)`
- `void destroyList(Sqlist *L)`
- `int BinarySearch(Sqlist *L, int value)` — **实现这个**

## main 测试代码

```c
int main() {
    Sqlist L;
    initlist(&L);

    /* ---- 测试组1：7元素表 ---- */
    int arr1[] = {1, 3, 5, 7, 9, 11, 13};
    buildList(&L, arr1, 7);
    printf("测试表："); printlist(&L);
    printf("\n");

    printf("查找 7：位序=%d（预期 4）\n",   BinarySearch(&L, 7));
    printf("查找 1：位序=%d（预期 1）\n",   BinarySearch(&L, 1));
    printf("查找 13：位序=%d（预期 7）\n",  BinarySearch(&L, 13));
    printf("查找 6：位序=%d（预期 0）\n",   BinarySearch(&L, 6));
    printf("查找 -1：位序=%d（预期 0）\n",  BinarySearch(&L, -1));
    printf("查找 99：位序=%d（预期 0）\n",  BinarySearch(&L, 99));

    /* ---- 测试组2：单元素表 ---- */
    int arr2[] = {5};
    buildList(&L, arr2, 1);
    printf("\n单元素表 [5]：\n");
    printf("查找 5：位序=%d（预期 1）\n", BinarySearch(&L, 5));
    printf("查找 3：位序=%d（预期 0）\n", BinarySearch(&L, 3));

    /* ---- 测试组3：空表 ---- */
    destroyList(&L);
    initlist(&L);                     // 重置为空表
    printf("\n空表查找 1：位序=%d（预期 0）\n", BinarySearch(&L, 1));

    destroyList(&L);
    return 0;
}
```
