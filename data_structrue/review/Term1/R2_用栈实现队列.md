# R2：用栈实现队列

## 题目

用**两个栈**实现队列的 `push`（入队）和 `pop`（出队）操作。不允许用数组/链表直接存储元素，只能用栈的 `push`/`pop`/`top`/`empty`。

## 涉及知识

栈的 LIFO 特性 + 两个栈配合模拟 FIFO

## 思路

```
入队: 一律 push 到 stack1
出队: 如果 stack2 为空 → 把 stack1 全部倒进 stack2（顺序反转）
      从 stack2 弹出栈顶
```

```
入队 1,2,3:  stack1 = [1,2,3]（栈顶=3）
出队:         stack1 全部倒入 stack2 → stack2 = [3,2,1]（栈顶=1）
              弹出 stack2 → 1 ✅
再次入队 4:  stack1 = [4]
出队:         stack2 还有 [3,2] → 直接弹 2
```

**关键点**：不用每次都倒——stack2 里还有数据时直接从这里出。

## 结构体

```c
typedef struct {
    SqStack stack1;
    SqStack stack2;
} MyQueue;
```

SqStack 复用你写过的顺序栈（`MaxSize` 设为足够大）。

## 需要实现的函数

| 函数 | 功能 |
|------|------|
| `void InitQueue(MyQueue *q)` | 初始化两个栈 |
| `void EnQueue(MyQueue *q, int x)` | 入队 |
| `int DeQueue(MyQueue *q, int *x)` | 出队，成功 1，队空 0 |
| `int IsEmpty(MyQueue *q)` | 判空 |

## 测试用例（C）

```c
int main() {
    MyQueue q;
    InitQueue(&q);
    int x;

    EnQueue(&q, 10);
    EnQueue(&q, 20);
    EnQueue(&q, 30);

    DeQueue(&q, &x);
    printf("出队=%d（预期 10）\n", x);
    DeQueue(&q, &x);
    printf("出队=%d（预期 20）\n", x);

    EnQueue(&q, 40);
    DeQueue(&q, &x);
    printf("出队=%d（预期 30）\n", x);
    DeQueue(&q, &x);
    printf("出队=%d（预期 40）\n", x);

    printf("空队出队返回=%d（预期 0）\n", DeQueue(&q, &x));

    return 0;
}
```
