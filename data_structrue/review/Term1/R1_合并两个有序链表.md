# R1：合并两个有序链表

## 题目

给定两个**升序**单链表（带头结点），合并为一个新的升序单链表，原链表保持不变。

## 涉及知识

链表遍历 + 双指针归并（和顺序表 Q4 同一思路，只是载体从数组换成了链表）

## 示例

```
输入: L1 = 1→3→5  L2 = 2→4→6
输出: 1→2→3→4→5→6
```

## 要求

1. 新链表在堆上分配（`malloc` / `new`）
2. 带头结点
3. 双指针只遍历一次，O(n₁ + n₂)

## 结构体

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```

## 函数签名

```c
LinkList MergeTwoLists(LinkList L1, LinkList L2);
```

## 测试用例（C）

```c
int main() {
    int a1[] = {1, 3, 5}, a2[] = {2, 4, 6};
    LinkList L1 = BuildList(a1, 3);
    LinkList L2 = BuildList(a2, 3);

    LinkList L3 = MergeTwoLists(L1, L2);
    printf("合并: "); PrintList(L3);
    printf("预期: 1→2→3→4→5→6\n");

    // 空链表
    LinkList empty = InitList();
    LinkList L4 = MergeTwoLists(L1, empty);
    printf("有一方空: "); PrintList(L4);
    printf("预期: 1→3→5\n");

    // 两个都空
    LinkList L5 = MergeTwoLists(empty, empty);
    printf("都空: "); PrintList(L5);
    printf("预期: (空表)\n");

    return 0;
}
```

## 进阶

用递归再实现一遍 `LinkList MergeTwoListsRecursive(LinkList L1, LinkList L2)`，体会递归在链表上的"缩小问题规模"。
